Module 01

Classification of Signals & Systems

Energy/Power • Periodicity • LTI • Causality • Stability

1. CT vs. DT Signals

Continuous-Time (CT) $x(t)$ is defined for all real $t \in \mathbb{R}$. Discrete-Time (DT) $x[n]$ is defined only at integer sample indices $n \in \mathbb{Z}$.

2. Energy vs. Power

Normalized Energy: $E = \int_{-\infty}^{\infty} |x(t)|^2 dt$ (or $\sum |x[n]|^2$).
Average Power: $P = \lim_{T\to\infty} \frac{1}{2T}\int_{-T}^{T} |x(t)|^2 dt$.
Energy signal: $0 < E < \infty \implies P = 0$. Power signal: $0 < P < \infty \implies E = \infty$.

3. Periodic vs. Aperiodic

CT signal is periodic with fundamental period $T_0 > 0$ if $x(t + T_0) = x(t)$.
DT signal is periodic with integer $N_0 > 0$ if $x[n + N_0] = x[n]$. Note: $\cos(\omega_0 n)$ is periodic iff $\frac{2\pi}{\omega_0}$ is a rational number!

4. Even & Odd Symmetry

Even: $x(-t) = x(t)$, $x_e(t) = \frac{1}{2}[x(t) + x(-t)]$.
Odd: $x(-t) = -x(t)$, $x_o(t) = \frac{1}{2}[x(t) - x(-t)]$.
Every signal decomposes uniquely as $x(t) = x_e(t) + x_o(t)$.

Core System Properties (Crucial for 10-Mark University & GATE Questions)

Superposition + Shift
Linearity

For $a x_1(t) + b x_2(t) \to y(t)$, system is linear iff $y(t) = a y_1(t) + b y_2(t)$ for all inputs and scalars $a, b$. Watch out for squaring, $|x(t)|$, or non-zero initial conditions!

Time-Invariance (TI)

If $x(t) \to y(t)$, then $x(t - t_0) \to y(t - t_0)$. Time-varying scaling like $y(t) = t\,x(t)$ or $y[n] = x[-n]$ is time-varying.

Causality

Output $y(t_0)$ depends only on present and past inputs ($t \le t_0$). $y(t) = x(t+1)$ is non-causal; $y(t) = x(-t)$ is non-causal for $t < 0$.

Memory (Static vs. Dynamic)

Static (Memoryless) systems depend only on current input, e.g., $y(t) = 5x(t)$. Integrators, differentiators, and delays are dynamic (have memory).

BIBO Stability

Bounded-Input Bounded-Output: if $|x(t)| \le M_x < \infty$ for all $t$, then $|y(t)| \le M_y < \infty$. An ideal integrator $y(t) = \int_{-\infty}^t x(\tau)d\tau$ is BIBO unstable.

Invertibility

Distinct inputs must produce distinct outputs so an inverse system recovers $x(t)$ from $y(t)$. $y(t) = x^2(t)$ is not invertible.

Module 02

Standard Singularity Signals & Time Operations

$\delta(t), u(t), r(t)$ • Shifting • Scaling • Reversal
Unit Impulse $\delta(t)$ / $\delta[n]$

CT: $\delta(t) = 0$ for $t \ne 0$, $\int_{-\infty}^{\infty}\delta(t)dt = 1$. Sifting property: $\int x(t)\delta(t-t_0)dt = x(t_0)$.
DT: $\delta[n] = 1$ for $n = 0$, and $0$ otherwise.

Unit Step $u(t)$ / $u[n]$

CT: $u(t) = 1$ for $t > 0$, $0$ for $t < 0$. Derivative of step is impulse: $\frac{d}{dt}u(t) = \delta(t)$.
DT: $u[n] = 1$ for $n \ge 0$, $0$ for $n < 0$. First difference: $u[n] - u[n-1] = \delta[n]$.

Unit Ramp $r(t)$ & Exponential

Ramp: $r(t) = t\,u(t) = \int_{-\infty}^t u(\tau)d\tau$; $\frac{d}{dt}r(t) = u(t)$.
Real exponential $e^{at}u(t)$ decays for $a < 0$ and grows for $a > 0$.

Module 03

LTI Systems & Convolution

Convolution Sum & Integral • Impulse Response $h(t)/h[n]$

Discrete-Time Convolution Sum

$$y[n] = x[n] * h[n] = \sum_{k=-\infty}^{\infty} x[k]\,h[n-k] = \sum_{k=-\infty}^{\infty} h[k]\,x[n-k]$$

If $x[n]$ has length $N_1$ and $h[n]$ has length $N_2$ (finite duration), the linear convolution $y[n]$ has length $N_1 + N_2 - 1$.

Continuous-Time Convolution Integral & LTI Rules

$$y(t) = x(t) * h(t) = \int_{-\infty}^{\infty} x(\tau)\,h(t-\tau)\,d\tau$$

Causal LTI: $h(t) = 0$ for $t < 0$. BIBO Stable LTI: $\int_{-\infty}^{\infty}|h(t)|dt < \infty$ (or $\sum |h[n]| < \infty$). Cascaded LTI systems multiply or convolve: $h_{eq} = h_1 * h_2$.

Module 04

Fourier Series & Fourier Transform (CTFT & DTFT)

CTFS • CTFT • DTFT • Parseval's Theorem

CT Fourier Series (CTFS)

Periodic CT signal with $\omega_0 = \frac{2\pi}{T_0}$: $$x(t) = \sum_{k=-\infty}^{\infty} c_k e^{jk\omega_0 t}, \quad c_k = \frac{1}{T_0}\int_{T_0} x(t)e^{-jk\omega_0 t}dt$$

CT Fourier Transform (CTFT)

Aperiodic CT signal: $$X(\omega) = \int_{-\infty}^{\infty} x(t)e^{-j\omega t}dt, \quad x(t) = \frac{1}{2\pi}\int_{-\infty}^{\infty} X(\omega)e^{j\omega t}d\omega$$ Duality: rectangular pulse in time $\leftrightarrow$ $\text{sinc}$ in frequency.

DTFT & Parseval's Relation

DTFT is always $2\pi$-periodic in $\Omega$: $X(e^{j\Omega}) = \sum_{n=-\infty}^{\infty} x[n]e^{-j\Omega n}$.
Parseval (Energy): $\int_{-\infty}^{\infty}|x(t)|^2 dt = \frac{1}{2\pi}\int_{-\infty}^{\infty}|X(\omega)|^2 d\omega$.

Module 05

Laplace Transform (s-Plane) & Z-Transform (z-Plane)

ROC Rules • Poles & Zeros • Stability & Causality

Laplace Transform & s-Plane ROC

$$X(s) = \int_{-\infty}^{\infty} x(t)e^{-st}dt, \quad s = \sigma + j\omega$$

  • ROC is always a vertical strip parallel to $j\omega$-axis and contains no poles.
  • Right-sided signal: $\text{Re}(s) > \sigma_{\max}$; Left-sided: $\text{Re}(s) < \sigma_{\min}$.
  • Causal LTI is BIBO stable iff all poles lie strictly in the Left Half Plane (LHP, $\text{Re}(s) < 0$).

Z-Transform & z-Plane ROC

$$X(z) = \sum_{n=-\infty}^{\infty} x[n]z^{-n}, \quad z = r e^{j\Omega}$$

  • ROC is a circular ring/annulus centered at origin with no poles.
  • Causal DT signal ($x[n]=0$ for $n<0$): ROC is $|z| > r_{\max}$ (exterior of outermost pole).
  • LTI is BIBO stable iff ROC includes the unit circle ($|z| = 1$); causal + stable $\iff$ all poles inside $|z| < 1$.

Module 06

Sampling Theorem & GATE / University Exam Tricks

Nyquist Rate • Aliasing • High-Yield Formulas

Nyquist Rate & Aliasing Frequency Calculator

For a bandlimited signal with maximum frequency $f_m$ (in Hz): Nyquist Rate $f_N = 2 f_m$, Nyquist Sampling Interval $T_s = \frac{1}{2 f_m}$. If sampled at $f_s < 2 f_m$, high-frequency components fold back (aliasing)!

High-Yield GATE & University Exam Traps to Avoid

Topic Common Student Mistake Correct Rule
Product of Signals Assuming Nyquist rate of $x_1(t)x_2(t)$ is $\max(2f_1, 2f_2)$. Convolution in frequency adds bandwidths: Nyquist rate is $2(f_1 + f_2)$!
Time Scaling & Period Forgetting time-axis scaling when finding fundamental period of $x(at)$. If $x(t)$ has period $T_0$, then $x(at)$ has period $\frac{T_0}{|a|}$.
Initial Value Theorem Applying $\lim_{s\to\infty} s X(s)$ without checking pole excess. Requires $x(t)$ to have no impulse at $t = 0^+$ and $\deg(\text{den}) > \deg(\text{num})$ for strictly proper cases.
DT Periodicity Treating every discrete cosine $\cos(\Omega_0 n)$ as periodic. Periodic iff $m = \frac{2\pi}{\Omega_0}$ is a positive rational number ($k/N$); then $N_0 = \text{lcm}$ of denominators.
